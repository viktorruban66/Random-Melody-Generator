🎵 Random Melody Generator — создавай музыку за секунду

> «Случайность — это новый хит»

**Random Melody Generator** — это набор консольных утилит для генерации случайных мелодий.  
Программа создаёт последовательности нот с различными длительностями, динамикой и темпом, а также может воспроизводить их через системный beep или экспортировать в MIDI-файл.

## 🚀 Особенности
- 🎶 Генерация случайных мелодий с настраиваемыми параметрами: количество нот, диапазон, тональность, темп.
- 🎼 Поддержка различных длительностей: целые, половинные, четвертные, восьмые, шестнадцатые.
- 🔊 Воспроизведение через системный beep (или встроенные звуковые функции).
- 📝 Экспорт мелодии в текстовый файл (список нот с частотами и длительностями).
- 🎹 Поддержка аккордов (опционально).
- 🎨 Цветной вывод в терминале.
- ⚡ Параметры командной строки для настройки генерации.

## 🛠️ Установка и запуск

Для звука используется `beep` (Linux) или `winsound` (Windows).  
**Установка beep (Linux):** `sudo apt install beep`

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python melody_generator.py`            |
| Go         | стандартная библиотека               | `go run melody_generator.go`            |
| JavaScript | Node.js, `fs`                        | `node melody_generator.js`              |
| Java       | стандартная библиотека               | `javac MelodyGenerator.java && java MelodyGenerator` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand`, `colored` (crates)           | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby melody_generator.rb`              |
| PHP        | стандартная библиотека               | `php melody_generator.php`              |
